# Identify SOAP contracts independently of server generation

ChangeScope identifies a SOAP Contract Boundary from WSDL qualified names, operations, message structure, portable XML Web Services metadata, and explicit Workspace Catalog mappings rather than from a WildFly or JBoss product name, deployment name, Java name, or endpoint URL. JBoss EAP and AS generations, WildFly generations, `javax.*` versus `jakarta.*`, and JBossWS Native versus CXF remain evidence flavors because the target estate spans these generations and a container migration must not create a new logical contract identity. The first capability fully models portable JAX-WS/Jakarta XML Web Services evidence and common JBossWS descriptors; recognizable JAX-RPC, Axis, dynamic `Dispatch`, and unproven runtime configuration remain Unresolved Items until a later evidence adapter can prove them.
