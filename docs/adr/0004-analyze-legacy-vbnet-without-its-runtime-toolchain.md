# Analyze legacy VB.NET without its runtime toolchain

ChangeScope analyzes VB.NET 2003 WinForms repositories from source-controlled VB, solution, project, designer, resource, configuration, SQL, and local metadata without requiring Visual Studio, .NET Framework, a compiler, MSBuild, application execution, database access, or COM registration. This sacrifices complete compiler, runtime, and binary resolution in exchange for repeatable local analysis and practical deployment in security-sensitive legacy environments; behavior that the indexed evidence cannot prove remains an Unresolved Item. A future opt-in Build Evidence Import may strengthen conclusions only when it records the producing source snapshot and toolchain provenance, and it must not become a prerequisite for the default capability.
